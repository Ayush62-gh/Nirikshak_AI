# Local Setup & Port Allocation

This document outlines the local development setup and assigned ports for all services in the Nirikshak AI project.

## Service Port Assignments

| Service | Technology / Framework | Local Port | URL |
| :--- | :--- | :--- | :--- |
| **Backend** | Python + FastAPI | `8000` | `http://localhost:8000` |
| **ML Service** | Python (OCR / Computer Vision) | `5001` | `http://localhost:5001` |
| **Rule Engine** | Python / Logic Engine | `5002` | `http://localhost:5002` |
| **Frontend** | React / Next.js | `3000` | `http://localhost:3000` |

> **Note:** Please confirm these port assignments with the team before overriding local configurations.
